\# Secure Enterprise System Monitoring and Incident Analysis



\## Project Overview

This project demonstrates practical system analysis, application error investigation, failed-login monitoring, and automated reporting using sample enterprise system event data.



\## Objectives

\- Analyze system events by severity.

\- Identify recurring application errors.

\- Detect and summarize failed login attempts.

\- Generate system health reports and dashboard data.

\- Document findings, test cases, and incident investigations.



\## Tools and Technologies

\- Python

\- PowerShell

\- SQLite and SQL

\- Microsoft Excel

\- CSV-based log analysis



\## Project Structure

\- `01\_Requirements/` — System requirements

\- `03\_Test\_Cases/` — Sample event data and test-case register

\- `04\_SQL\_Analysis/` — Database creation and SQL analysis scripts

\- `05\_Automation/` — Analysis scripts, reports, and dashboard

\- `06\_Incident\_Reports/` — Application and login investigation reports



\## Key Findings from Sample Data

\- Analyzed 13 sample system events.

\- Identified 3 CRM application errors.

\- Summarized 4 failed-login events.

\- Generated event severity summaries and system health recommendations.



These findings are based on fictional sample data and do not represent a confirmed security incident.



\## How to Run

Use the Python executable installed on your computer to run the scripts. Update file paths if the project is moved to another location.



Example:



`python event\_summary.py`



Run the PowerShell failed-login analysis script with:



`powershell -ExecutionPolicy Bypass -File .\\Analyze-FailedLogins.ps1`



\## Learning Outcomes

This project demonstrates practical skills in log analysis, requirements documentation, test-case development, SQL data analysis, scripting, incident reporting, and dashboard reporting.
